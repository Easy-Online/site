Conversion notes

Text PDFs: reading order is approximated from text coordinates. Scanned PDFs: require OCR, which this module does not perform. XLSX/CSV: preserve page and line structure rather than recreating arbitrary visual tables. Privacy: processing occurs in browser memory and exports are downloaded locally.
